## DB·퀘스트 구조 변경 (2026-11-06)

- JPA + MySQL 8.4로 변경. H2 제거. Docker Compose로 로컬 DB 실행.
- 지역 → 분야별 장소 → 순차 퀘스트 구조. 9개 테이블과 주문 상태 JSON 저장.
- 전통시장(장소 5)은 문화 분야, 퀘스트 501~504로 변경. 기존 나머지 장소는 단일 퀘스트 유지.
- 가챠 body에 `requestId` 필수. 코인 내역·뽑기 결과 저장 및 재시도·동시 요청 보호.
- `introStory`, `imageUrl` 추가. 초기 이미지 URL은 비워 두었다.
- 변경된 API·응답은 [API.md](API.md), 스키마는 [ERD.md](ERD.md) 참고.
